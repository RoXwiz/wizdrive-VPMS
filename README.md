# 🚗 WizDrive - Vehicle Parts Management System


---

## 📝 Project Overview

**WizDrive** is a comprehensive Vehicle Parts Management System designed to streamline the import, sale, and inventory management of vehicle parts and accessories. It supports international sellers from Taiwan, China, and Japan, offers multi-currency handling, and automates the customs clearance process.

**Key Features:**

* Multi-country seller support
* Multi-currency transaction handling
* Inventory and stock management with real-time updates
* Order tracking and management
* Customs port clearance workflow
* Social media sales integration
* Innovative feature for automated stock alerts

---

## 🛠️ Tech Stack

* **Frontend:** React.js / Vue.js
* **Backend:** Node.js 
* **Database:** MongoDB
* **Authentication:** JWT / OAuth
* **Deployment:** Docker / AWS 

---

## ⚡ Features

* Add, update, delete vehicle parts (CRUD operations)
* Track orders and inventory in real-time
* Multi-currency support for international transactions
* Customs clearance process management
* Social media integration for product sales
* Alerts & notifications for stock levels (innovative feature)

---

## 🎯 Usage

* Register as a seller or admin
* Add vehicle parts to inventory
* Track orders and update stock
* Manage customs clearance for imports
* Monitor multi-currency sales and transactions
