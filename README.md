# 🚗 WizDrive Web System

WizDrive is a comprehensive web platform designed to simplify the **import and sale of vehicle parts in Sri Lanka**. It connects international sellers from Taiwan, China, and Japan with local buyers while supporting logistics, customs clearance, and AI-powered demand forecasting.

---

## 🔑 Core Features

### 👤 User Roles

- **Admin**: Manages the platform, approves sellers, and oversees all transactions.
- **Seller**: Uploads and manages vehicle parts inventory.
- **Buyer (User)**: Browses products, places orders, and tracks delivery.
- **Logistics Team**: Handles customs clearance and shipping updates.

---

## 🚀 Main Functionalities

### 📦 Product Management (CRUD)
- Sellers can add, update, or delete vehicle part listings.
- Buyers can browse, search, and view details of products.
- Admins approve and manage listings.

### 🛒 Order Management (CRUD)
- Buyers place orders; sellers confirm and fulfill them.
- System provides real-time order status updates.
- Admins monitor all transaction activities.

### 💱 Multi-Currency Support
- Prices are shown in seller's local currency (TWD, CNY, JPY) and auto-converted to LKR.
- Uses a currency conversion API for real-time exchange rates.

### 📑 Customs Port Clearing
- Automates import documentation generation.
- Customs officers update clearance statuses.
- Notification system informs buyers and sellers of clearance progress.

### 🤖 AI-Based Demand Prediction
- Uses AI to analyze sales trends.
- Recommends stock restocking quantities to sellers.
- Prevents overstocking and shortages.
